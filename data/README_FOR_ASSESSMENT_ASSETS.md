# Aurik Tech Lead Assessment Assets

This package contains dummy assessment assets for the Founding Tech Lead take-home assignment.

## Included Files
- `expected_output_context.md` — downstream output context for the assignment
- `event_type_reference.md` — basic context for vendor event and alert types
- `asset_reference.csv` — machine and plant reference
- `line_reference.csv` — line and plant reference
- `vendor_api_samples/` — sample JSON payloads and edge-case batches
- `seed_data/` — CSV files for local testing and ingestion

## Usage Notes
- The assets are intentionally small enough for a take-home assignment.
- Vendor data formats are not fully aligned.
- You are free to choose your own implementation approach and stack.
- Build a practical, reviewable backend service rather than an over-engineered platform.
